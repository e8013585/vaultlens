VaultLens
Version 1.0.0

Real-time CS2 inventory pricing, float values, pattern detection, sticker values, and trade analytics — all on one screen.

🏪 Chrome Web Store 📦 GitHub Repository 🐛 Report an Issue
🔒 Privacy

VaultLens is free and open source. No data is collected or tracked. All API calls go directly from your browser to public APIs. Your API key is stored locally and never transmitted to VaultLens servers.

Data Sources
Prices (Mode 1) PricEmpire API v3
Prices (Mode 2) Skinport Public API
Float / Pattern CSGOFloat Public API
Doppler Listings CSFloat API
Known Limitations
  • CSGOFloat API has rate limits (~5 req/s). Float loading may be slow for large inventories.
  • Fade % values are approximate (±0.5%) based on community-researched seed tables.
  • Pattern tier data reflects community consensus; rankings may not match all buyer preferences.
  • Crimson Web pattern detection uses seed range approximations; visual verification recommended.
  • Trade lock detection relies on Steam's description format, which may vary.
